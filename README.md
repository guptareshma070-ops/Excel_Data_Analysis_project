# Vrinda Store Sales Analysis 2022 (Excel)

## 📌 Project Overview
This repository contains a data analysis project done completely using Microsoft Excel. The dataset was mostly pre-cleaned, so the main focus of this project was to verify the data structure, organize it, and analyze customer purchasing behavior across the year 2022.

## 🎯 Problem Statement & Business Questions
The objective of this project is to analyze store sales data and solve business tracking problems using Excel. This analysis answers the following key questions:
* Compare the sales and orders using a single chart.
* Identify which month received the highest sales and orders.
* Analyze gender-based purchasing behavior (Men vs. Women) in 2022.
* Understand the different order statuses across the year.
* List the top 10 states contributing the most to overall sales.
* Find the relation between age and gender based on order counts.
* Identify which sales channel and category are contributing to maximum sales.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** The primary tool used for data verification and dashboard creation.

## ⚙️ Key Features Executed (As Visible in Dashboard)
* **Interactive Slicers:** Added dynamic slicers for "Month", "Channel", and "Category" to filter the dashboard instantly.
* **Pie Chart & Donut Chart:** Used for analyzing "Men Vs Women" demographics and "Orders Channels" market share.
* **Bar Charts (Horizontal & Vertical):** Used to display "Sales: Top 5 States", "Orders: Age VS Gender", and "Orders Vs Sales" monthly trends.
* **Data Verification:** Formatted and structured the rows and columns properly before building the final report.

## 📊 Key Insights From the Data
* **Top Sales State:** Maharashtra is the leading state with nearly 2.99 million in sales, followed closely by Karnataka.
* **Order Channels:** Amazon, Myntra, and Flipkart are the top channels, with Amazon alone capturing 35% of total orders.
* **Gender Demographics:** Women are the primary buyers, making significantly more purchases than men across all age groups.
* **Order Fulfillment:** The store has an excellent delivery success rate, with 92% of orders successfully "Delivered".
